# 📊 Stock Analysis & Backtesting Pipeline

This project is a modular pipeline for fetching, processing, analyzing, and backtesting stock market data (currently focused on AAPL).  
It demonstrates a full workflow from raw data ingestion to strategy evaluation.

---

## 🚀 Features

- Data ingestion from Alpha Vantage API
- Data cleaning and preprocessing
- Feature engineering:
  - Moving averages (MA_5, MA_10, MA_20)
  - Returns
  - Volatility
- Exploratory data analysis
- Correlation analysis
- Backtesting framework
- Visualization of:
  - Correlation matrix
  - Price with signals
